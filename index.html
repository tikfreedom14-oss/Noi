01

ภาพรวมแผน

18 สัปดาห์เต็ม เริ่มจันทร์ 13 ก.ค. → แข่งอาทิตย์ 15 พ.ย. 2026. ยึดหลัก 3:1 (หนัก 3 สัปดาห์ · ลด 1 สัปดาห์) เหมาะกับวัย masters ที่ฟื้นตัวช้ากว่า. โครงสัปดาห์: จันทร์พัก · อังคาร speed · พุธ easy · พฤหัส tempo/MP · ศุกร์ strength · เสาร์ easy+strides · อาทิตย์ long run.

⚠️ อ่านก่อนเริ่ม — เช็ค volume ปัจจุบัน
  • สัปดาห์ที่ 1 ตั้งไว้ที่ ~42 km/สัปดาห์
  • ถ้าตอนนี้พี่วิ่ง ต่ำกว่า 35 km/wk → ลด W1-W3 ลง 20% แล้วค่อยไล่ตามตารางที่ W5
  • กฎเหล็ก: เพิ่ม volume ไม่เกิน +10%/สัปดาห์ · แผนนี้คุมไว้แล้วทุกสัปดาห์
  • Cut-off rule: เจ็บ >3/10 หรือเจ็บแหลมเฉพาะจุด (ข้อ/เอ็น/กระดูก) → เปลี่ยน quality/long วันนั้นเป็น Easy สั้นหรือพักทันที · ตารางคือแนวทาง ไม่ใช่คำสั่ง
W1-3 (+ deload W4)

เฟส 1 · Base

สร้างฐาน endurance · long 16→20km · speed เบา · tempo สั้น. ปรับตัวเข้าสู่การซ้อมเป็นระบบ.

W5-7 (+ deload W8)

เฟส 2 · Build

เพิ่ม volume · เริ่ม MP run · long ถึง 26km · tempo ยาวขึ้น. volume แตะ 64 km/wk.

W9-11 (+ deload W12)

เฟส 3 · Peak 1

long 28→30km · MP run 12-13km · เริ่มใส่ MP ท้าย long run. volume สูงสุด 71 km/wk ที่ W11.

W13-15

เฟส 4 · Peak 2

🎯 W14 = long run ไกลสุด 32km (last 10km MP + ซ้อม fueling เต็มรูปแบบ) — 4 สัปดาห์ก่อนแข่ง.

W16-17

เฟส 5 · Taper

ลด volume 71 → 47 → 36 km/wk (ลด ~50%). รักษาความคุ้นเพซ MP ไว้ · ขาสดขึ้นทุกวัน.

W18 · 9-15 พ.ย.

เฟส 6 · Race Week

วิ่งเบาสั้นๆ + strides · ศุกร์-เสาร์พักเต็ม ไม่ยกเวท · Carb-load · อาทิตย์ 15 พ.ย. = RACE DAY 🏆

02

โซน & เพซ

เพซคำนวณจากเป้า Sub 3:30 (MP 4:58) และ Half PR 4:29/km. สังเกต: tempo เร็วกว่าเพซ Half ที่แข่งจริง — เพราะ threshold คือเพซที่ยืนได้ ~60 นาที.

❤️ Heart Rate Zones

ยังไม่มีค่า Max HR / LT จริงของพี่ — ตารางนี้ใช้ % ของ Max HR + talk test ไว้ก่อน. ใส่ตัวเลข bpm จริงเมื่อทดสอบแล้ว.

โซน% Max HRความรู้สึก (talk test)ใช้กับ
🔬 หาค่า HR จริง — อย่าใช้สูตร 220 − อายุ
  1. สูตร 220 − อายุ คลาดเคลื่อนได้ ±10-12 bpm → zone ผิดทั้งชุด
  2. ถ้ามี Garmin: ทำ Lactate Threshold test (guided) → ได้ LT bpm + LT pace จริง · จัดลงตารางแล้ว: W2 อังคาร + re-test W12 พฤหัส
  3. หรือดูจากการแข่ง: HR เฉลี่ยตอนแข่ง Half ≈ LT ของพี่ (บวกลบเล็กน้อย)
  4. ระหว่างนี้ให้เชื่อ talk test เป็นหลัก — เบา = คุยได้เป็นประโยค
03

ตาราง 18 สัปดาห์

กดแต่ละสัปดาห์เพื่อดูครบ 7 วัน (จันทร์พัก). Long run: 16→18→20→14→22→24→26→18→28→30→30→20→30→32→24→18→12→🏆 · ตัวหนา = deload · 32km ครั้งเดียว ที่ W14.

04

วิธีแล่นแต่ละวัน

ทุก session: warm-up jog 10-15 นาที → เนื้อหลัก → cool-down jog 5-10 นาที + ยืดเหยียด.

05

Race Pacing

วันแข่ง อาทิตย์ 15 พ.ย. 2026. กดเลือกเป้าตามสภาพร่างกาย/อากาศวันนั้น.

A · 3:35ปลอดภัย/ร้อน
B · 3:30เป้าหลัก
C · 3:20วันฟอร์มดี
ระยะเวลาสะสมเพซ/kmหมายเหตุ
🏁 กลยุทธ์วันแข่ง
  1. km 1-10: คุมช้ากว่าเป้า 3-5 วิ/km · อย่าตื่นเต้นออกเร็ว
  2. km 11-30: ล็อกเพซเป้าให้นิ่ง · ดื่มน้ำทุกจุด · Gel ทุก 25-30 นาที (เป้า 60-75g คาร์บ/ชม.) + เกลือแร่
  3. km 31-42: ช่วงพิสูจน์ · ถ้าแรงเหลือค่อยเร่ง 5 km สุดท้าย
  4. อากาศ Bangsaen ร้อน → ถ้า HR พุ่งผิดปกติ ถอยไปเป้า A (เชื่อ HR มากกว่านาฬิกา)
  5. Half PR ทำนายไว้ที่ 3:17 — Sub 3:30 มี buffer เยอะ อย่าฝืนตั้งแต่ต้น
06

เคล็ดลับ + Masters

🎯 80/20

~80% ของ mileage แล่นเบา (Zone 2) · ~20% หนัก. กับดักใหญ่สุด = แล่นหนักปานกลางทุกวัน — เหนื่อยสะสมแต่ไม่พัฒนา.

🛌 Masters Recovery

วัย 45-49 ฟื้นตัวช้ากว่าหนุ่ม ~20-30%. นอนให้พอ · deload คือส่วนสำคัญ ไม่ใช่ขี้เกียจ. Escape valve: สัปดาห์ไหนฟื้นไม่ทัน ตัด interval วันอังคารออกได้เลยโดยไม่ถือว่าหลุดแผน — Long + MP/Tempo คือ quality ที่ตัดไม่ได้.

🍚 Fueling

Long run 90 นาที+ เริ่ม Gel ทุก 25-30 นาที (เป้า 60-75g คาร์บ/ชม.) + เกลือแร่ (อย่ารอหิว). ฝึกกินในซ้อมให้ท้องชิน — W14 คือการซ้อมใหญ่. Carb-load 2-3 วันก่อนแข่ง.

💪 Strength (ศุกร์)

Squat · RDL (พับสะโพก) · Glute Bridge · Core · Calf Raise. สร้าง posterior chain ให้รักษาฟอร์มตอนล้า km 30+ — ปลายมาราธอนพังเพราะสะโพกยุบ ไม่ใช่ปอด.

👟 รองเท้า

หมุนเวียนหลายคู่ = กระจายจุดรับแรง ลดบาดเจ็บซ้ำที่เดิม. Easy=คู่นุ่มซัพพอร์ต · Long=คู่ทน · Tempo/MP=คู่เบา. วันแข่งใช้คู่ที่ซ้อมมาแล้วเท่านั้น.

⏱️ HR vs Pace

Easy/Long → ดู HR (กันเผลอเร็ว) · Tempo/MP → ดู pace · Interval → ดู pace · Hill → ดู RPE. วันร้อน/ล้า เชื่อ HR มากกว่าเสมอ.

07

Recovery Budget · ปรัชญาการซ้อม

3 หลักที่ใช้ตัดสินใจทุกวัน: Easy ต้องเบาจริง · Recovery คืองบก้อนเดียว · ไม่ต้องซ้อมจนหมดแรง. ตัวเลขบอกครึ่งหนึ่ง ความรู้สึกบอกอีกครึ่ง.

✅ เช็ค 4 อย่าง — Easy วันนี้เบาพอไหม

1. Heart Rate — อยู่ในโซน Easy (Zone 2) ไม่ไต่ขึ้นเรื่อยๆ
2. Pace (5:50-6:15) — ร้อน / นอนน้อย / ล้าสะสม → เพซที่ช้าลงคือเพซที่ถูกต้องของวันนั้น
3. RPE 3-4/10 — ยังผ่อนคลาย พูดเป็นประโยคได้ ไม่ฝืน
4. การหายใจ — หายใจทางจมูกได้สบาย ลึก ต่อเนื่อง

4 อย่างไปทางเดียวกัน = Easy ทำหน้าที่จริง · ขัดกัน = เชื่อ HR และร่างกาย

💰 Recovery Budget — งบก้อนเดียว

การนอน · ความเครียดงาน · อาหาร/น้ำ/เกลือแร่ · load สะสม — ทั้งหมดแบ่งใช้งบฟื้นตัวก้อนเดียวกัน. ถ้าความสามารถฟื้นตัวลดลง Easy Run เดิมก็ไม่ใช่ Easy Run อีกต่อไป แม้เพซเท่าเดิม.

⭐ วิธีวัดว่าพอหรือยัง: ไม่ได้วัดจากวันนั้น แต่วัดจาก quality session ครั้งถัดไป (Tempo 4:20-4:30 / MP 4:55-5:00 / Interval) — ทำได้ตามเป้า = ที่ผ่านมาเหมาะสม · ทำไม่ได้ = ต้องพักเพิ่ม

🏋️ ไม่ต้องซ้อมจนหมดแรง (RIR 1-3)

หยุดก่อนหมดแรง 1-3 ครั้ง ให้ความแข็งแรงใกล้เคียงกัน แต่ความล้าสะสมต่ำกว่ามาก. เป้าของเราไม่ใช่ยกเวทให้เก่ง แต่คือรักษาคุณภาพโปรแกรมวิ่งทั้งสัปดาห์.

ถามก่อนทุก session: ต้องการ adaptation อะไร · จำเป็นต้องหมดแรงจริงไหม · recovery ที่จ่ายคุ้มไหม · จะกระทบการวิ่งใน 1-3 วันข้างหน้าไหม

🛌 Masters (45-49) — งบฟื้นตัวน้อยกว่า

ฟื้นตัวช้ากว่านักวิ่งหนุ่ม ~20-30% = งบฟื้นตัวก้อนเล็กกว่า ที่ volume 68-71 km/wk. หลัก RIR และวินัย Easy จึงสำคัญกับพี่มากกว่าคนอื่นในกลุ่ม — สัปดาห์ไหนฟื้นไม่ทัน ตัด interval วันอังคารออกก่อน (Long + MP/Tempo คือ quality ที่ตัดไม่ได้)

⚠️ กับดักที่เจอบ่อยสุด
  1. Easy เร็วเกินวันนี้ → ไม่รู้สึกอะไรเลย แต่ 2 วันถัดมา tempo ทำไม่ครบ / long run หนักผิดปกติ
  2. แล้วเข้าใจผิดว่า "ซ้อมหนักไม่พอ" ทั้งที่จริงคือ "ความล้าที่เกิน" ไม่ใช่ "สิ่งที่ขาด"
  3. เพซช้ากว่าเป้าแต่ HR สูงกว่าเป้า = สัญญาณล้าสะสม ไม่ใช่ "วันฟอร์มไม่ดี"
  4. ไม่มีวันเบาจริงหลายวันติด = เสี่ยง overreach แม้แต่ละวันดูไม่หนัก
🌱 มุมที่ควรจำไว้
  1. ร่างกายไม่ได้เปลี่ยนจากการซ้อมยอดเยี่ยมครั้งเดียว แต่จากการซ้อมที่ "ดีพอ" ซ้ำแล้วซ้ำอีก เป็นเดือน
  2. โปรแกรมทำไม่ครบ / ย้ายวัน / ตัดบางเซสชัน — เป็นเรื่องปกติของคนที่มีชีวิตจริง ไม่ใช่ความล้มเหลว
  3. อย่าให้คะแนนตัวเองจากสิ่งที่ยังทำไม่ได้ จนลืมมองสิ่งที่ทำได้แล้ว
  4. สัปดาห์ที่ไม่ดีที่สุด ≠ สัปดาห์ที่สูญเปล่า
