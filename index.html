01

ภาพรวมแผน

แผน 16 สัปดาห์ แบ่งเป็น 4 เฟส ยึดหลัก 3:1 (หนัก 3 สัปดาห์ · ลด 1 สัปดาห์) เหมาะกับนักวิ่งวัย masters ที่ต้องการการฟื้นตัวมากขึ้น. โครงสัปดาห์: จันทร์พัก · อังคาร speed · พุธ easy · พฤหัส tempo/MP · ศุกร์ strength · เสาร์ easy+strides · อาทิตย์ long run.

เฟส 1 · Base (W1-4)

สร้างฐาน endurance · long run 16→22km · speed เบา · ปรับตัวเข้าสู่การซ้อม

เฟส 2 · Build (W5-9)

เพิ่ม volume + เริ่ม MP run · long run ถึง 28km · tempo ยาวขึ้น

เฟส 3 · Peak (W10-13)

long run ไกลสุด 30-32km · MP practice เข้มข้น · ซ้อม fueling

เฟส 4 · Taper (W14-16)

ลด volume 40% ให้ร่างกายสด · รักษาความคุ้น pace · พร้อมแข่ง

02

โซน & เพซ

เพซคำนวณจากเป้า Sub 3:30 (MP 4:58). งานเบาดู HR · งานเร็วดู pace · long run คุม Zone 2 เป็นหลัก.

03

ตาราง 16 สัปดาห์

กดแต่ละสัปดาห์เพื่อดู 6 วัน (จันทร์พัก). Long run ไต่: 16→18→20→14→22→24→26→18→28→30→32→22→race prep. ตัวเลขหนา = สัปดาห์ deload.

04

วิธีแล่นแต่ละวัน

ทุก session: warm-up jog 10-15 นาที + strides → เนื้อหลัก → cool-down jog 5-10 นาที + ยืด.

05

Race Pacing

ตารางเพซวันแข่ง Bangsaen42. กดเลือกเป้าตามสภาพร่างกาย/อากาศ.

ระยะเวลาสะสมเพซ/kmหมายเหตุ
🏁 กลยุทธ์วันแข่ง
  1. km 1-10: คุมช้ากว่าเป้า 3-5 วิ/km อย่าออกตัวเร็ว
  2. km 11-30: ล็อกเพซเป้าให้นิ่ง · ดื่มน้ำทุกจุด
  3. km 31-42: ถ้าแรงเหลือค่อยเร่ง · Gel ทุก 35-40 นาที
  4. อากาศ Bangsaen ร้อน → ถ้า HR พุ่ง ถอยไปเป้า A (เชื่อ HR)
06

เคล็ดลับ + Masters

🎯 80/20

~80% ของ mileage แล่นเบา (Zone 2) · ~20% หนัก. กับดัก = แล่นหนักปานกลางทุกวัน — เหนื่อยแต่ไม่พัฒนา.

🛌 Masters Recovery

วัย 45-49 ฟื้นตัวช้ากว่าหนุ่ม — นอนให้พอ, deload สำคัญ, วันพักคือวันพักจริงๆ. ฟังร่างกายมากกว่าตาราง.

🍚 Fueling

Long run 90 นาที+ เริ่มเติม Gel ทุก 35-40 นาที. ฝึก fueling ในซ้อม ไม่ใช่แค่วันแข่ง. Carb-load 2-3 วันก่อนแข่ง.

💪 Strength

วันศุกร์: squat, RDL (พับสะโพก), glute bridge, core, calf raise. สร้าง posterior chain รักษาฟอร์มตอนล้า km 30+.

👟 รองเท้า

หมุนเวียนหลายคู่ลดบาดเจ็บ. Easy=คู่ซัพพอร์ตนุ่ม · Long=คู่ทน · Tempo/MP=คู่เบา. วันแข่งใช้คู่ที่ซ้อมมาแล้ว.

⏱️ HR vs Pace

Easy/Long → ดู HR (กันเผลอเร็ว) · Tempo/MP → ดู pace · Interval → ดู pace. วันร้อน/ล้า เชื่อ HR มากกว่า.
